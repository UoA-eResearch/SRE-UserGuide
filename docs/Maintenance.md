# Service Availability & Maintenance

## Scheduled Maintenance

The SRE undergoes scheduled maintenance on the **first Tuesday of every month**.<br>

During this time, the environment will be in **maintenance mode and unavailable for the full day**.<br>

> [!WARNING]
> Security updates will be applied to virtual desktops, and virtual desktops will be rebooted.
> This will interrupt any processes you may have running on the desktops.

Any other SRE maintenance actions outside of these windows will be announced by an outage message on the web portal.
